语音识别 (STT)
启用语音识别API

开启后，语音通话时将使用第三方API进行语音识别，替代浏览器内置识别。你说的话会通过API转成文字发送给联系人。

API 服务商
OpenAI Whisper 配置

支持所有兼容 OpenAI Whisper API 格式的服务（如 Groq、本地部署等），修改 Endpoint 即可。

Google Cloud Speech 配置

使用 Google Cloud Speech-to-Text API v1。需在 Google Cloud Console 启用该服务。

腾讯云语音识别配置

使用腾讯云一句话识别 API。需在腾讯云控制台开通语音识别服务。

讯飞语音识别配置

使用讯飞实时语音转写 API。需在讯飞开放平台创建应用。

Azure Speech 配置

使用 Azure Cognitive Services Speech-to-Text。需在 Azure 门户创建语音资源。

自定义 STT API

自定义API需接受 POST multipart/form-data，字段名 file (音频文件 webm/wav)，返回 JSON 格式 {"text": "识别结果"}。

AI 生图服务
启用生图功能

开启后，联系人可以在聊天中根据描述生成图片。AI会智能判断何时需要生图，也可以手动请求。

生图服务商
OpenAI DALL·E 配置

使用 OpenAI 的 DALL·E 图片生成 API。支持所有兼容 OpenAI 格式的中转站。

Stability AI 配置

使用 Stability AI 的图片生成 API。需在 platform.stability.ai 获取 API Key。

Google Gemini Imagen 配置

使用 Google Gemini / Imagen API 生成图片。需在 Google AI Studio 获取 API Key。

通义万相 配置

使用阿里巴巴通义万相 API。需在阿里云 DashScope 平台获取 API Key。

SiliconFlow 配置

使用 SiliconFlow 硅基流动 API。提供多种开源生图模型，性价比高。

NovelAI 配置
通过 Netlify/Cloudflare 等服务端转发请求，推荐大多数用户使用。
填写你自己搭建的 NovelAI 反向代理地址。代理需转发请求到 image.api.novelai.net 并返回原始响应。

使用 NovelAI 的图像生成 API。需要 NovelAI 订阅（Opus/Tablet/Scroll）。API Key 在 NovelAI 设置中获取。
⚠️ NovelAI 官方API不支持浏览器直连(CORS)，如果「服务端代理」报错，请尝试「直连」(需科学上网) 或「自定义代理」。

自定义生图 API

自定义API需兼容 OpenAI 图片生成格式。POST JSON: {"model":"xxx","prompt":"描述","n":1,"size":"1024x1024"}，返回 {"data":[{"url":"..."}]} 或 {"data":[{"b64_json":"..."}]}。
